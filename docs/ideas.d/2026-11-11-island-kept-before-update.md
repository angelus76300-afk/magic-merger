section: Quality of life

- **The island from before the update** (Claude, 11 November, lens 6: what happens when the player leaves). The page keeps one copy of the island as it was saved before each new version of the game first opened it, and the New island dialog offers "Go back to your island from before the update" for a week. What the player feels: an update can never cost them their island; if a release breaks something on it, they get yesterday's island back with one tap instead of a fresh one. What it adds: the player's half of the save guard of 11 November, which only stops older code from reading a newer save; a newer version that misreads an older save is still caught only by tests. Cost: S to M; no API call; a second copy of the island in local storage (a giant island is about 0.6 MB gzipped, so it needs the same "storage full" check as today's save, and is skipped when it does not fit). Claude.
